===ITA===
QueryQuest è un board game educativo in stile cyberpunk per ripassare le basi della programmazione giocando. L'avvio non richiede installazioni: basta un server HTTP statico. 
Puoi scegliere la tua pedina tra 3 modelli 3D.


Le regole di gioco sono: 
Scegli una pedina 3D che si muove lungo un tabellone tridimensionale lanciando un dado a ogni turno. Quando si ferma su una casella, il gioco pesca un esercizio di programmazione il cui tema dipende dalla casella stessa: viola per Java, magenta per HTML/CSS, dorata per SQL, bluastra per il pool misto.
Risposta corretta: +10 punti.
La casella rossa STOP contiene una penalità: risposta sbagliata −10 punti, corretta  0.

Gli esercizi sono bilingue IT/EN e di due tipi: scelta multipla cliccabile (spesso con snippet di codice reale) e "completa il codice", dove si scrive la parola mancante nel campo di testo e si preme CONFERMA. Ogni risposta apre una spiegazione . 
Il cambio lingua avviene in tempo reale anche durante i quiz.


Il progetto è costruito in JavaScript vanilla (nessun framework) con Three.js per la scena 3D; 
il dado, le pedine e il tabellone con Blender in formato glb.

===ENG===
QueryQuest is an educational board game in cyberpunk style for revising the basics of programming by playing. Getting started requires no installation: all you need is a static HTTP server. You can choose your token from 3 3D models.

The rules of the game are: Choose a 3D token that moves around a three-dimensional board by rolling a dice at each turn. When it stops on a tile, the game draws a programming exercise whose topic depends on the tile itself: violet for Java, magenta for HTML/CSS, golden for SQL, bluish for the mixed pool. Correct answer: +10 points. The red STOP tile carries a penalty: wrong answer −10 points, correct one 0.

The exercises are bilingual IT/EN and of two kinds: clickable multiple choice (often with real code snippets) and "complete the code", where you type the missing word into a text field and press CHECK. Each answer opens an explanation. Language switching happens in real time, even during quizzes.

The project is built with vanilla JavaScript (no framework) and Three.js for the 3D scene; the dice, the tokens and the board are modeled with Blender in glb format.
